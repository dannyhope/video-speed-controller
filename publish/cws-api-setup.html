Google Cloud & OAuth (one-time)

Enable Chrome Web Store API

Google Cloud Console → Chrome Web Store API — pick or create a project, then Enable.

Configure OAuth consent screen

OAuth consent screen — External, app name + support email, add yourself as a Test user. Your Google Account needs 2-step verification to publish extensions.

Create OAuth client (Web application)

Credentials → Create credentials → OAuth client ID — type Web application. Authorised redirect URI: https://developers.google.com/oauthplayground. Save the client ID and client secret.

Generate refresh token

OAuth 2.0 Playground — gear icon → Use your own OAuth credentials → paste client ID and secret. Input scope: https://www.googleapis.com/auth/chromewebstore → Authorise → Exchange authorization code for tokens → copy the refresh token.

Step-by-step: chrome-webstore-upload-keys · Official: Use the Chrome Web Store API

Publisher & extension IDs

Copy publisher ID

Developer Dashboard → Publisher → Settings (also visible in the dashboard URL).

Copy extension ID

Developer Dashboard → your item → the 32-character ID in the URL or under Build → Package.

Export for the agent

Set the five environment variables

Terminal or shell profile — paste real values, then tell Cursor to publish again. Do not commit these to the repo.

export CLIENT_ID="your-client-id.apps.googleusercontent.com"
export CLIENT_SECRET="your-client-secret"
export REFRESH_TOKEN="your-refresh-token"
export PUBLISHER_ID="your-publisher-id"
export EXTENSION_ID="your-32-char-extension-id"

After export, say “publish the update” in Cursor. The agent will upload publish/video-speed-controller.zip and submit for review (DEFAULT_PUBLISH).
