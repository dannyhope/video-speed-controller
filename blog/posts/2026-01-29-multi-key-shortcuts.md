# Power User Tip: Multiple Keys Per Shortcut

Quick update: you can now assign multiple keys to the same shortcut. Useful if you switch between keyboard layouts or just want options.

## How It Works

In settings, enter keys separated by commas:

- **Speed up:** `d, l, ]` – any of these will increase speed
- **Speed down:** `a, j, [` – any of these will decrease speed
- **Reset:** `s, k, \` – any of these will reset to 1×

## Why This Matters

**Vim users:** Map speed controls to `h, j, k, l` style navigation
**AZERTY keyboards:** Add alternative keys that make sense for your layout
**Muscle memory conflicts:** If `a/s/d` conflicts with a site's shortcuts, add alternatives

## Setting It Up

1. Open settings (click extension icon or press `Cmd+Shift+V`)
2. In the shortcut fields, enter your keys separated by commas
3. Settings save automatically

The first key listed is shown in keyboard hints on the on-screen controls.
