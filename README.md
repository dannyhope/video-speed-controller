# Video Speed Controller

Chrome extension that lets you control HTML5 video playback speed on any website with customisable keyboard shortcuts and on-screen controls.

## Defaults

| Key | Action |
|-----|--------|
| **D** | Speed up |
| **A** | Slow down |
| **S** | Reset / toggle normal speed |
| **G** | Toggle skip silence (when captions exist) |

Change speeds and shortcuts from the extension popup (or the ⚙ button on the video controls).

## Load unpacked (local)

1. Open `chrome://extensions/`
2. Enable **Developer mode**
3. **Load unpacked** → select this folder
4. Open a page with a video and try **D** / **A**
